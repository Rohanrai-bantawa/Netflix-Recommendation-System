# 🎬 Netflix Recommendation System

A movie recommendation system built using Python and Machine Learning to recommend movies based on user preferences.

## 📌 Project Overview

This project uses Collaborative Filtering and Singular Value Decomposition (SVD) to predict movie ratings and generate personalized movie recommendations.

## 🎯 Objectives
- Analyze Netflix movie rating data.
- Perform data cleaning and preprocessing.
- Explore user ratings and movie patterns.
- Build a recommendation model using SVD.
- Predict movie ratings.
- Generate Top 5 movie recommendations.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Surprise
- Jupyter Notebook

## 🧠 Algorithm
- Collaborative Filtering
- Singular Value Decomposition (SVD)

## ⚙️ Project Workflow
1. Data Loading
2. Data Preprocessing
3. Exploratory Data Analysis
4. Model Building
5. Model Evaluation using RMSE
6. Rating Prediction
7. Movie Recommendation
